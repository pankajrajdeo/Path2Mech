# Path2Mech: AI-Assisted H&E Screening Tool

LungMAP3 Group 1 — Aim 1

Automated pipeline for H&E whole-slide image analysis:
- Tissue region classification using LazySlide
- GeoJSON annotation export
- Gradio side-by-side viewer (raw H&E vs. AI-annotated candidates)

Run in Google Colab (L4 GPU recommended).
